# FlowOps 原型 · 视觉设计说明

> 本文替代原 DESIGN-01 的位置：作为原型的**视觉令牌真源**说明。全部令牌落于 `assets/css/tokens.css`，明暗两套主题同源于一组变量。

## 1. 设计定位

**运维控制台（Ops Console）**：面向运维/工程用户的长时间驻留界面，深色为默认。

- **信息密度优先**：13px 基准字号、紧凑表格（9px 行内边距），一屏承载更多运行状态
- **状态即视觉焦点**：任何列表/卡片中，最先被注意到的应是"什么东西不正常"
- **克制的技术感**：深空底色 + 微网格 + 顶部高光线，装饰服务于层级而非风格化

## 2. 色彩体系

### 背景五级明度（深 → 浅）

| 令牌 | 深色值 | 用途 |
|---|---|---|
| `--bg-void` | `#05070c` | 页面最底、登录页、画布 |
| `--bg-base` | `#0a0e16` | 应用主背景 |
| `--bg-panel` | `#10151f` | 面板/卡片 |
| `--bg-raise` | `#161d2b` | 悬浮/表头悬停/按钮底 |
| `--bg-inset` | `#0c1018` | 内嵌凹陷：输入框、代码块、日志面板 |

### 语义色（运维语义固定：成功=绿 / 失败=红，永不变换）

| 令牌 | 深色值 | 语义 |
|---|---|---|
| `--ok` | `#2fd27d` | 成功、在线、通过 |
| `--fail` | `#f2555a` | 失败、离线、危险操作 |
| `--warn` | `#f5a623` | 警告、等待、超时、停止中 |
| `--info` | `#38bdf8` | 调度中、运行中、链接提示 |
| `--pri` | `#3d7dff` | 品牌主色：主按钮、选中态、导航激活 |
| `--mut` | `#a78bfa` | 互斥锁等特殊语义 |

每个语义色配套 `*-soft`（约 13% 透明度的底色）与 `--glow-*`（发光），状态徽标 = soft 底 + 同色描边 + 图标发光。

### 文字三级 / 边框两级

`--t1 #e9eef6`（主）→ `--t2 #9aa7ba`（次）→ `--t3 #5f6d82`（弱）；`--line` / `--line-faint` 两级描边。

## 3. 状态语义表（tone + marker 双区分）

**颜色之外必须叠加形态差异**（无障碍要求：色弱用户靠动画/形状区分）。实现于 `ui.js` 的 `statusTag()`：

### 任务 9 态

| 状态 | 中文 | tone | marker |
|---|---|---|---|
| PENDING | 等待中 | 灰 | ● 实心点 |
| SCHEDULING | 调度中 | info 蓝 | ◌ 脉冲 |
| RUNNING | 运行中 | info 蓝 | ↻ 旋转 |
| STOPPING | 停止中 | warn 黄 | ◌ 脉冲（≠调度中的蓝，同形不同色） |
| SUCCESS | 成功 | ok 绿 | ✓ |
| FAILED | 失败 | fail 红 | ✕ |
| TIMEOUT | 超时 | warn 黄 | 🕐 时钟 |
| STOPPED | 已停止 | 灰 | ■ 方块 |
| PARTIAL | 部分成功 | warn 黄 | ● |

### 步骤 11 态

在任务 9 态语义基础上补充：`NOT_STARTED` 灰点 / `WAITING_DEPENDENCY` info 时钟 / `WAITING_RESOURCE` warn 点 / `RETRYING` warn 旋转 / `SKIPPED` 灰方块（预留，一期不产生）。

## 4. 布局规范

- 侧栏 230px（导航分组 + 激活态左侧发光条），顶栏 62px（**底部渐变分割线**为强识别符号）
- 内容区 `padding: 20px 22px`；页面头 = 标题 + 副标（含 PRD 出处）+ 右侧操作区
- 面板统一 10px 圆角、顶部 1px 高光线；网格间距 14px
- 数字（编号/资源/时长）一律 `--font-mono`，保证纵向对齐
- 控件高度 33px（sm 28px），与工程 Element Plus small 尺寸对齐

## 5. 关键组件

| 组件 | 说明 |
|---|---|
| `StatusTag` | 上表的状态徽标，全站唯一状态渲染口径 |
| 资源条 `rbar` | 细轨道 + `n/m` 等宽数字，≥70% 转黄、≥90% 转红并发光 |
| 诊断树 `tree` | 等宽字体的 `├ └` 树（调度诊断、Runbook、建议操作），可点击建议项 |
| 日志面板 | 深底等宽，stdout/stderr/系统行分色，尾部跟随可暂停 |
| 时间线 `tline` | 审计聚合、心跳记录、操作链路 |
| diff 表 | 字段级审计：旧值删除线红底 / 新值绿底 |
| 步骤条 `stepper` | 凭据轮换等流程化操作 |
| Toast / Modal / Drawer | 危险操作强制填原因（≥5 字符，对齐 42234） |

## 6. 落地纪律（工程阶段继承）

1. **禁止硬编码颜色**：组件与页面只引用令牌；CI lint 扫描十六进制色值（仅 tokens.css / theme 覆盖文件豁免）
2. **新增令牌流程**：先补 `tokens.css`（深浅两套同步）→ 再使用
3. **状态渲染只走 `statusTag` / 字典**：禁止页面内私写状态颜色与文案
4. 虚拟滚动等性能要求见 `docs/04-架构文档-前端.md` §6.4（本原型不涉及）
