# FlowOps 原型 V0.2（评审版）

> 「智能工作流调度与监控平台」一期可交付原型。基于 `prd/智能工作流调度与监控平台_PRD_V0.2.md`（含 v3 架构评审回写 R-1~R-8）从零设计，供产品评审与需求确认。

> **V0.2e 变更（详情双页重设计 · 信息密度与排版专项）**：
> ① **工作流详情**（`workflow-detail.html`）：新增**运营指标带**（近 7 天实例含状态堆叠条 / 成功率 / 平均·最快·最慢耗时 / 下次执行 / 并发占用 / 拓扑规模，6 格发丝线密排）；「DAG 预览」升级为**拓扑 × 最近运行**——节点叠加最近实例的步骤状态点与耗时角标、完成边绿色高亮、**点击节点直达任务详情对应步骤（`?step=`）**；左栏下方新增**最近实例**三列宽卡，右栏新增**关键信息栏**（运行配置摘要 / 通知与告警 / API 触发）；运行历史 Tab 新增**成功率汇总 + 近 14 天耗时趋势图 + 状态筛选 + 耗时与起止列**（失败原因内联展示）；版本 Tab 新增**版本对比 diff 弹窗**（与审计 PUBLISH_WORKFLOW 的 diff 口径一致）；并发与亲和 Tab 新增**配置继承链可视化**（超时/重试两条链逐层演示 §12.5）。页头加密：ID 一键复制、项目归属、更新时间。

## 打开方式

**零依赖、零构建**：直接双击任意页面（`file://` 协议即可），或 `python -m http.server` 后访问。
建议从 **`login.html`**（登录进入）或 **`pages.html`**（评审索引，含每页看点）开始。

- 无外网依赖：无 CDN、无字体库、无图标库（内联 SVG）
- 数据为内存 Mock（`assets/js/mock.js`），刷新即复位
- 推荐浏览器：Chrome / Edge 最近两个大版本（同工程基线）
- **如遇样式错乱（黑块/旧配色），按 Ctrl+F5 强制刷新**——外链 CSS 更新后浏览器可能用旧缓存

## 重点演示链路（评审建议按此顺序点）

1. **任务详情（本轮核心，`task-detail.html?scene=running`）**
   - **场景控制台**：同一任务在 运行中 / 等待调度 / 全部成功 / 失败(重试耗尽) / 超时 五个阶段的完整快照一键切换——等待调度场景展示**调度链路时间线**（提交→并发检查→变量快照→入队→等待节点）与**调度诊断**（队列 7/12、阻塞约束、near-miss 节点、ETA、建议）；失败场景展示**结构化失败归因 + 重试历史**（每次尝试的节点/退出码/结论）；超时场景展示超时终止语义。
   - **真实菱形 DAG**：7 步骤 8 依赖（数据校验/数据清洗并行汇入特征计算，评分与入库并行），完成路径绿色高亮、当前步骤发光，点击节点联动右侧详情。
   - **步骤详情**：参数注入来源层标注、解析后的完整命令、输出声明产出、**资源申请 vs 实际峰值**（斜纹条，V1.1 资源画像的数据地基）、互斥锁等待说明。
   - **变量快照**：22 项六层变量 + 层过滤器，敏感项脱敏并标注；**逐步骤仿真日志**（运行中步骤持续追加批次进度，支持暂停跟随/断线重连演示/运维视图授权）。
2. **任务列表（`task-list.html`）**：18 个任务覆盖 9 态 × 4 触发方式 × 3 项目；**切换右上角演示角色（业务人员）→ 数据行按 DataScope 收敛为 PRJ-0001**；任意筛选同步到地址栏（分享/刷新不丢）；每行「详情」直达对应场景。
3. **算子资产化**（`operator-list` → `operator-detail` → `operator-version`）：8 个算子；Spark数据清洗含 3 个版本（v1 下线/v2 发布/v3 默认）；参数模板（敏感标记）、输出声明、**试运行**（选节点 → 实时日志 → 另存为默认参数）。
4. **工作流编排**（`workflow-editor`）：画布拖拽算子、端口连线（箭头指向、自动拦截成环/自环/重复边）、备注节点可拖动、变量引用只列可达上游、互斥锁与继承链提示、**脏标记**（未保存修改角标）、**校验跑全部 10 条规则**（把「报告推送」切到「旧版库存导出工具(已停用)」可现场触发规则 7）、发布生成不可变版本。
5. **工作流详情（`workflow-detail`）**：运营指标带（实例/成功率/耗时/下次执行/并发/规模）、**拓扑 × 最近运行**（节点带步骤状态与耗时，点击直达任务详情对应步骤）、最近实例与关键信息栏、版本冻结与回溯 + **版本对比 diff**、触发器（Cron 未来 5 次预览/锁定版本/补跑/失败通知）、运行历史（成功率汇总 + 耗时趋势 + 状态筛选）、手动运行（勾选「模拟并发超限」演示 40901 分支）、**配置继承链可视化**。
6. **回填双闸门（`backfill.html`）**：预览（±30 分钟冲突、FORBID→eff_conc 收敛为 1）→ 哈希 → 提交；预览后改任何配置 → 哈希作废 → 42231 拦截。
7. **凭据安全（`credential-list.html`）**：明文永不可见红线、指纹脱敏、引用计数禁删（12/1/3/0 四档演示）、三步灰度轮换。
8. **平台健康度（第 19 页）**：调度器主备 + 租约 30s 倒计时、DB/Redis、节点在线率、队列水位含队头阻塞、**最近调度决策表**（DISPATCHED/DEFERRED/BLOCKED/SKIPPED）、平台自身告警与 Runbook。
9. **审计（`audit-log.html`）**：22 条记录覆盖全部 12 个域（含集群/节点/队列/回填/试运行/强制释放互斥锁），字段级 diff、trace_id 串联、按对象聚合时间线。

## 与上游文档的关系

- 需求口径**唯一以 PRD V0.2（含 v3 回写）为准**；本原型不引入 PRD 之外的新需求。
- 变量引用语法采用钉死口径 `${step.{步骤名}.output.{变量名}}`（D-20 / R-2）。
- 互斥锁语义为**步骤级、出队后竞争**（R-5）：提交路径不返回 40904，阻塞原因走调度诊断。
- 任务状态为 **9 态**（含 `STOPPING`）；步骤实例 11 态（`SKIPPED` 预留）。
- 权限点 47 个（含 `operator:read` / `workflow:read`，R-4）。
- 页面总数 19（含平台健康度，R-1/R-6）。

## 已知简化边界（如实告知）

- Mock 数据刷新即复位；除任务详情的状态流转模拟外，操作不改变共享数据。
- 画布支持拖拽/连线/参数配置/校验演示；撤销重做、框选、备注节点双击编辑等工程细节未做。
- 日志流、心跳、租约倒计时为模拟节奏（加速以便观察）。
- 后端契约以 `docs/07-接口实现规范.md` 为真源；本原型的每个页面即一个验收场景（PRD §20）。
